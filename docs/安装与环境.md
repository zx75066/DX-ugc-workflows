# 安装、环境与常见问题

## 直接交给智能体安装

打开自己的视频项目后，把 [首页「让智能体自动安装与加载」中的完整指令](../README.md#让智能体自动安装与加载) 复制给 Codex 等具有文件和命令执行能力的智能体，即可让它获取最新正式版、核对校验值、安装到项目、验证六条路线，并说明加载状态。

安装完成后在目标项目开始新一轮对话，输入 `$higgsfield-ugc-workflows` 和具体任务。若当前应用没有识别到 Skill，按智能体给出的实际状态重新打开项目或重启应用。只有文件复制成功时，不能据此认定当前应用已经原生加载。

这一步不会连接账号或生成视频。缺少 Higgsfield MCP 不影响零积分模式；少积分和完整视频的远程生成仍需自行配置服务。仅支持文字聊天、无法访问文件或执行命令的智能体不能代为完成本机安装。

## 第一次使用

建议先使用零积分入口确认本地安装和素材读取正常，再根据需要配置生成服务。完整示例见仓库根目录的 `示例需求.md`。

## Python

本地安装和校验需要 Python 3.9+。macOS / Linux 使用 `python3 --version` 检查；Windows 若只有 `python` 命令，可手动安装，并将示例命令中的 `python3` 替换为 `python`。不要在 Windows PowerShell 直接运行 Bash 安装脚本。

## 如何连接 Higgsfield MCP

本仓库不包含账号认证配置或固定服务器地址。请通过你实际使用的 Higgsfield MCP 提供方文档完成连接和授权。连接后让 Codex 检查实时工具清单：

- 少积分：Soul 2.0 图片生成、任务查询、结果下载；若支持，还需生成前费用查询。
- 完整视频：所选路线要求的图像和视频模型、参考图上传或导入、任务查询；后处理按路线补齐。

工具名称、模型名称和参数可能发生变化，应以实时定义为准。服务缺失时不能把提示词交付当作成片交付，也不能声称远程流程已测试成功。

## 后处理依赖

完整流程的转写脚本包含 faster-whisper / Whisper 等实现适配，是否能使用取决于本机安装和模型缓存。网页截图需要 Node.js、Playwright 及其浏览器；视频拼接与字幕烧录需要 FFmpeg / FFprobe，字幕所用字体需要本机可用。仓库没有附带这些运行时、模型权重、字体或浏览器。按实际执行路线安装依赖，无需为了零积分模式安装所有后处理工具。

## Skill 没出现

确认当前项目内存在 `.agents/skills/higgsfield-ugc-workflows/SKILL.md`，而非多嵌套了一层 `skill` 目录。重新打开项目或重启 Codex，显式输入 `$higgsfield-ugc-workflows`。

## 仓库名和 Skill 名为什么不同

公开仓库名为 DX-ugc-workflows，内部调用名为 higgsfield-ugc-workflows。保持内部名称是为了兼容各流程中现有的路径和命令。

## 模式和素材问题

- 零积分需要已有模特图和产品图，支持 PNG、JPEG、WebP。
- 少积分需要产品图，并明确允许生成一张模特图；若已有模特图，会转入零积分。
- 零积分和少积分适用于真人测评、试穿、教程、开箱；纯产品展示和网页演示使用完整模式。
- 涉及膏体、凝胶或液体时，需要真实颜色与透明度证据，不能根据包装猜测。
- 零积分仅指 Higgsfield 生成调用为零，不代表 Codex 使用或后续手工生成视频没有费用。

## 更新和备份

Bash 安装器默认在同名 Skill 已存在时停止。使用 `--replace` 更新时，旧目录移动至 `.agents/skill-backups/`，避免被当作第二个 Skill 发现。手动安装时也请将旧目录移到 `.agents/skills/` 之外，再复制新版本。

## 公开反馈

在 Issues 中写明操作系统、版本、执行模式、所选路线和报错。上传示例时使用你有权公开的素材，并删除访问令牌和账号认证内容。
