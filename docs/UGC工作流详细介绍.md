# 电商 UGC 短视频工作流服务说明

## 一、这套工作流解决什么问题

这是一套面向 TikTok、Reels、Shorts 等竖屏内容场景的电商 UGC 短视频生产方案。它不是简单地把商品图交给模型“自由发挥”，而是先确认视频的销售任务，再依次锁定人物、商品、口播、镜头、动作、参考图和验收标准，尽量减少 AI 视频中常见的商品变形、颜色失真、人物跳变、多手、错拿、假动作和口型不一致等问题。

服务可覆盖从前期策划到成片制作的不同深度。客户既可以只获取一套可直接用于生成的视频提示词，也可以选择从人物、分镜到视频、字幕与质检的完整制作。对于已经有模特图和产品图的客户，我们优先复用现有素材，不重复消耗生成积分。

## 二、六类内容路线

系统不会因为客户提供了一个商品链接，就机械地套用“网页展示”模板。路线由最终画面中最重要的主体和动作决定。

| 内容路线 | 画面核心 | 适合的营销任务 | 关键控制点 |
|---|---|---|---|
| 真人产品测评 | 一位模特面对镜头讲解、试用或推荐商品 | 真实体验、种草、口碑感、卖点解释 | 人物身份稳定、口型、产品持握、真实使用动作 |
| 纯产品展示 | 产品是唯一主角，人物只以手部或局部视角辅助 | 质感展示、功能演示、品牌视觉 | 产品形状、尺寸、标签、材质与运动物理 |
| 网站或 SaaS 演示 | 真人讲解，同时展示真实网页或应用页面 | 网站介绍、软件功能、店铺或商品页导览 | 使用真实页面截图，不凭空生成界面；讲解与画面按时间对应 |
| 试穿与穿搭 | 模特真正穿着指定服装或配饰，展示版型和质感 | OOTD、版型展示、材质细节、搭配灵感 | 服装身份、穿着状态单向连续、垂坠和纹理、前后造型一致 |
| 产品教程 | 模特按真实顺序完成多个使用步骤 | 教程、使用方法、降低购买顾虑 | 步骤不可虚构，前后状态连续，步骤字幕与动作一致 |
| 开箱与揭晓 | 从密封包装开始，以看到产品和第一反应为高潮 | 新品开箱、礼盒、PR 包裹、惊喜揭晓 | 开箱前产品不提前出现，揭晓后包装不反复恢复 |

当多个方向同时存在时，以视频的主要动作和高潮为准。例如：客户给出商品链接，但画面只需要模特拿着商品测评，仍然采用真人产品测评；只有客户希望网页本身出现在视频中，才进入网站或 SaaS 演示路线。

## 三、三种执行模式

### 1. 零积分模式：已有模特图 + 已有产品图

适合已经准备好一张模特参考图和一张产品参考图，希望先获得完整视频方案、自行在支持参考图的视频工具中生成的客户。

本模式不调用任何远程生图或生视频服务，不上传素材，也不消耗生成积分。工作流仍会完整完成以下内容：

- 素材有效性检查；
- 模特身份、服装、场景和光线特征锁定；
- 产品外观、角度、比例、标签、开合方式与使用方式分析；
- 膏体、凝胶、精华、液体等内容物颜色核验；
- 完整英文或指定语言口播；
- 带精确时间段的文本分镜；
- 每段视频的最终生成提示词；
- 两张参考图的固定上传顺序；
- 生成后的逐项质检清单。

这一模式交付的是完整的“策划与生成指令包”，不包含新生成的模特图、分镜图或视频成片。它适用于真人测评、试穿、教程和开箱；不直接用于纯产品路线或必须展示真实网页的 SaaS 路线。

### 2. 低积分模式：已有产品图，缺少模特图

适合已经有可靠产品图，但没有合适模特参考图的客户。系统只在人物环节生成一次模特图，并将人物图保存为后续可复用的固定资产；之后的口播、文本分镜、视频提示词、参考图顺序和质检清单均以文本方式完成，不继续消耗分镜和视频生成积分。

模特图使用 Soul 2.0 生成人物，默认采用适合竖屏人物参考的 3:4 构图与 2K 质量。产品图不会被送入人物生成环节，避免模型把商品错误地长在手上、衣服上或背景中。人物生成完成后，模特的面部、发型、年龄感、服装、场景和光线会被冻结，后续所有镜头沿用同一身份。

如果客户已经提供可用模特图，系统会自动优先采用零积分模式，不会为了“重新生成得更漂亮”而浪费一次人物积分。低积分模式同样适用于真人测评、试穿、教程和开箱，不适用于没有固定出镜人物的纯产品路线，也不适用于以真实网页合成为核心的 SaaS 路线。

### 3. 完整渲染模式：从策划到成片

适合希望获得可直接投放或进一步剪辑视频的客户。该模式在前述策划基础上继续完成必要的人物生成、视觉分镜、分镜精修、视频生成、结果检查，并根据项目需要进行片段拼接和字幕处理。

所有需要消耗积分的生成动作都会在提交前明确范围，不会在客户不知情的情况下从免费额度切换到付费积分。完整渲染模式的最终交付范围以订单确认内容为准，包括片段数量、总时长、字幕、拼接、比例、语言和是否需要发布版本。

## 四、客户需要提供的资料

为了减少返工，建议在开始前一次性确认以下信息：

| 信息 | 最低要求 | 用途 |
|---|---|---|
| 产品图片 | 至少一张清晰、无遮挡、能看清外形与标签的图片 | 锁定产品外观、比例、结构和可见角度 |
| 模特图片 | 零积分模式必须提供一张；低积分模式可不提供 | 锁定人物身份、服装、场景与光线 |
| 产品链接 | 可选，但建议提供 | 辅助理解名称、规格和已公开卖点；链接本身不等于画面素材 |
| 视频目标 | 测评、纯产品、网页演示、试穿、教程或开箱 | 选择正确的内容路线 |
| 时长与比例 | 例如 15 秒、9:16 | 决定口播字数、镜头数量和节奏 |
| 出镜要求 | 性别、年龄感、地区气质、发型、服装、场景 | 避免人物方向与品牌受众不符 |
| 语言与口音 | 例如英语、新加坡英语、美式英语 | 控制口播表达和语速 |
| 可使用卖点 | 客户确认过的功能、材质、规格和体验描述 | 防止夸大、误导或虚构功效 |
| 内容物证据 | 膏体或液体挤出后的真实颜色、透明度照片或文字确认 | 锁定膏体颜色，防止生成错误 |
| 包装参考 | 开箱项目可选提供真实外箱或礼盒图 | 还原真实包装；未提供时仅使用普通密封棕色快递箱 |

如果关键资料不足，工作流会停在对应关口并向客户确认，不会擅自猜测，也不会自动切换到更高积分的方案。

## 五、从素材到交付的完整流程

### 第一步：确认视频真正要卖什么

先明确这条视频的主要任务，是建立真实体验、展示功能、讲解步骤、表现穿着效果，还是制造开箱惊喜。只有目标明确，镜头结构、口播和产品动作才能围绕同一个结果服务。

### 第二步：检查并冻结参考素材

系统会确认模特图和产品图是否能正常读取、是否确实包含指定主体、清晰度是否足够支撑判断。随后形成两份连续性基准：

- 人物基准：面部特征、肤色、发型、年龄感、体型、服装、配饰、环境与光线；
- 产品基准：外形、尺寸感、材质、颜色、标签位置、瓶盖或泵头结构、可见角度与使用方式。

冻结后，后续镜头不得随意改变人物造型或产品设计。参考图只证明它真正展示的内容，未出现的产品背面、隐藏文字和内部结构不会被凭空补全。

### 第三步：完成产品真实性核验

产品信息只分析一次，并形成贯穿全部镜头的统一描述。重点核验：

- 商品是软管、瓶装、罐装、盒装还是其他结构；
- 开盖、按压、挤出、喷洒、涂抹或穿戴的真实方式；
- 人手中的合理尺寸和重量感；
- 品牌标签在参考图中的朝向和可见程度；
- 客户允许表达的卖点与不能承诺的功效；
- 产品在不同镜头中的状态变化，例如未开封、已开盖、已挤出、已使用。

这一层的目标不是“让产品看起来更神奇”，而是让画面中的产品始终像同一个真实商品。

### 第四步：锁定膏体或液体颜色

凡是会出现膏体、凝胶、乳霜、精华、油、乳液、喷雾、泡沫或其他内容物，都会单独锁定颜色和透明度。

有效证据包括：产品参考图中清楚可见的挤出物、客户提供的补充实拍图，或客户明确的文字确认。包装颜色、商品名称和成分名称都不能用来推断内容物颜色。例如，绿色包装不代表里面一定是绿色凝胶，“蜂蜜”字样也不能证明内容物一定是琥珀色。

一旦确认，颜色描述会原样复用到分镜和视频提示词中，并明确禁止色相和透明度漂移。若证据缺失或互相冲突，会先向客户确认，再继续涉及挤出或涂抹的镜头。

### 第五步：设计口播与镜头节奏

口播按真实时长控制信息密度。15 秒内容不会硬塞入过多卖点，也不会用冗长的 AI 式开场。英文表达以自然口语为主，优先形成“吸引注意—说明体验—展示证据—给出结论”的短链路。

每句话都会对应可见动作，避免出现“嘴上说正在挤出产品，画面却还没有打开盖子”的错位。对于不能从素材或客户资料中证明的疗效、测试数据、认证和绝对化结论，不会自行添加。

### 第六步：编排文本分镜

真人测评、试穿等路线可采用八段结构；产品、教程或开箱会按照各自规则使用适合的镜头数量。每个镜头不仅写“拍什么”，还明确：

- 起止时间；
- 景别、视角和拍摄距离；
- 人物所在位置与身体朝向；
- 左手和右手分别做什么；
- 产品位于哪只手、处于什么状态；
- 当前说哪一句话，采用同步口播还是画外音；
- 与上一镜头必须延续的细节。

八个镜头之间只有七次硬切，四个镜头之间只有三次硬切，最后一镜不会再追加无意义转场。这样可以避免模型把“八镜头”误解成八次切换，造成尾部黑帧或多余镜头。

### 第七步：生成最终视频提示词与参考图顺序

视频提示词会把静态分镜转换为具体动作、镜头运动、口播和精确切换时间，同时重复人物与产品的关键锚点。参考图在提示词中的编号与客户实际上传顺序必须完全一致。

默认顺序为：

1. `@Image1`：模特身份参考图；
2. `@Image2`：产品外观参考图。

如果客户明确要求产品图放在第一张，整套提示词和交付说明会统一改为产品优先，避免“文字说图一是产品，实际图一却是模特”的错配。零积分模式只使用这两张既有图片，不悄悄加入第三张参考图。

### 第八步：按清单验收

完整渲染模式会在生成后检查结果；零积分和低积分模式会交付同一套生成后检查标准，方便客户自行验收。建议逐镜冻结画面检查：

- 人物是否始终是同一个人，面部、发型和服装有无跳变；
- 产品形状、尺寸、颜色、标签和开合结构是否一致；
- 画面中是否只出现一个目标商品，有无复制或异常放大；
- 产品是否被旋转到参考图从未提供的未知角度；
- 是否始终只有两只手，有无第三只手、漂浮商品或手指穿模；
- 左右手动作是否符合分镜，是否一只手同时承担多个不可能动作；
- 开盖、挤出、涂抹是否遵循真实物理顺序；
- 膏体颜色、透明度和质地是否与锁定证据一致；
- 嘴型、发声时机和口播内容是否匹配；
- 镜头数量、硬切数量、总时长和参考图顺序是否正确。

## 六、人物一致性如何保障

人物并不是每个镜头重新设计一次。工作流会先建立统一身份描述，再在每段提示词中重复必要特征。除非客户明确要求换装或换场，否则面部、发型、服装、首饰、环境和光线均保持连续。

人物生成阶段不把商品放进画面。这样做是为了获得干净、稳定、可长期复用的模特资产，也能避免后续视频把一张错误商品“继承”到所有镜头。真正的产品只由独立产品参考图控制。

性别、年龄感、肤色、族裔气质、发型、服装、语言、口音和场景都以客户要求为准。客户未提供且会明显影响结果的信息，会先确认，不会根据产品品类或刻板印象替客户决定。

## 七、产品和手部动作如何保障

AI 视频最容易在手和产品发生接触时出错，因此工作流把动作拆到可检查的最小单位：一只手在一个时刻只承担一个主要动作，另一只手负责支撑、开盖或涂抹，不让两只手的职责含糊重叠。

例如软管产品的真实顺序应是：一只手稳定握住软管，另一只手打开盖子；盖子状态确认后再挤出；挤出的内容物先落到指定手指或皮肤位置，再进行涂抹。系统不会让产品在未开盖时直接出膏，也不会让模特同时拿产品、开盖、指向镜头和涂抹。

产品数量默认锁定为一个。除非客户明确要求组合装或多件展示，否则任何镜头都禁止出现复制商品。产品尺寸参照人物手掌和原始参考图控制，避免从普通随身物品突然变成超大包装。

## 八、不同模式的交付清单

| 交付内容 | 零积分 | 低积分 | 完整渲染 |
|---|:---:|:---:|:---:|
| 内容路线与执行参数 | ✓ | ✓ | ✓ |
| 产品分析与真实性约束 | ✓ | ✓ | ✓ |
| 膏体或液体颜色锁定 | ✓ | ✓ | ✓ |
| 模特连续性描述 | 基于客户图片 | 新生成并锁定 | 已有或新生成 |
| 完整口播或声音计划 | ✓ | ✓ | ✓ |
| 精确时间文本分镜 | ✓ | ✓ | ✓ |
| 最终视频生成提示词 | ✓ | ✓ | ✓ |
| 参考图上传顺序 | ✓ | ✓ | ✓ |
| 生成后验收清单 | ✓ | ✓ | ✓ |
| 新模特图 | 不生成 | 生成 1 张 | 按项目需要 |
| 视觉分镜图 | 不生成 | 不生成 | 按内容路线需要 |
| 视频成片 | 不生成 | 不生成 | ✓ |
| 拼接与字幕 | 不生成 | 不生成 | 按项目约定 |

零积分和低积分都能完整走完素材分析、创意策划、口播、文本分镜、视频提示词、参考图排序和验收标准这一整套流程。两者与完整渲染的区别，不是策划是否完整，而是是否继续代为生成视觉分镜和视频成片。

## 九、适用边界与风险说明

为了保证交付可信，以下边界会在项目开始前明确：

- 单张产品图只能锁定其真实可见角度，不能保证未展示侧面或背面的细节；
- 模糊、遮挡严重或标签不可读的图片会降低产品还原度；
- 没有真实证据时，不推断内容物颜色、包装内部结构或使用效果；
- 网站演示必须以真实页面截图为基础，不生成看似真实但实际不存在的页面；
- 提示词模式提供的是完整生成指令和验收标准，最终成片质量仍受客户所用视频模型、版本、参考图支持能力和生成随机性影响；
- 完整渲染也不能承诺每一次模型输出都一次通过，但会用前置锁定和逐项 QA 降低无效生成与返工；
- 涉及医疗、治疗、永久改善、保证效果等高风险表述时，只使用客户可证明且允许发布的说法。

客户可按以下格式提交需求：

```text
产品名称：
产品链接：
产品图：

目标内容：真人测评 / 纯产品 / 网页演示 / 试穿 / 教程 / 开箱
执行模式：零积分 / 低积分 / 完整渲染
视频时长：
画面比例：

场景要求：
语言与口音：
必须表达的卖点：
禁止表达的内容：
膏体或液体颜色与透明度：
```

提交后，系统会先核对信息完整度和执行模式，再进入制作。任何会影响产品真实性、人物身份或积分消耗的缺口，都会在生成前确认，而不是在成片后用返工补救。

## 十一、服务价值总结

这套工作流的核心价值不是单纯增加提示词长度，而是把短视频制作中最容易出错的决策提前固定：先选对内容路线，再锁定真实商品与人物，随后让口播、动作、镜头、参考图和验收标准保持一致。

对于预算敏感的测试项目，零积分和低积分模式可以先验证创意方向与生成方案；对于需要直接交付成片的项目，完整渲染模式再承接后续视觉制作。客户可以根据素材条件和预算选择执行深度，同时保留同一套产品真实性与质量控制标准。
