# Higgsfield UGC 工作流可分享版 v2.0

这是一个面向 Codex 的项目本地 Skill，用于规划和执行六类电商 UGC 视频工作流。安装包已经把主路由器、六条子流程、零积分模式、低积分模式、完整渲染规则、公开 Hook/Setting 预设和校验工具放在同一个目录中，不依赖原作者电脑上的固定路径。

本包不包含任何产品图、模特图、历史生成结果、账号信息、API Key 或付费额度。

## 能做什么

支持六类内容：

- 真人产品测评；
- 纯产品展示；
- 网站、SaaS、商店或商品页演示；
- 试穿与穿搭；
- 分步骤产品教程；
- 开箱与产品揭晓。

支持三种执行深度：

| 模式 | 需要提供 | 远程生成 | 主要交付 |
|---|---|---:|---|
| 零积分 | 1 张模特图 + 1 张产品图 | 0 次 | 产品分析、颜色锁定、口播、文本分镜、视频提示词、参考图顺序、验收清单 |
| 低积分 | 1 张产品图，允许生成模特 | 仅 1 次 Soul 2.0 人物图 | 新模特图 + 零积分模式的全部文本交付 |
| 完整渲染 | 按所选路线提供素材 | 按确认后的项目范围调用 | 人物、分镜、视频、质检，以及按需要进行拼接和字幕处理 |

零积分和低积分模式当前适用于真人测评、试穿、教程和开箱。纯产品路线没有固定出镜人物，不应强行套用双图模式；网站或 SaaS 路线需要真实网页截图、合成和字幕，也不属于双图提示词模式。

## 环境要求

### 零积分模式

- Codex Desktop 或支持项目本地 Skill 的 Codex 环境；
- Python 3.9 或更高版本；
- 两张位于当前项目可访问目录内的有效 PNG、JPEG 或 WebP 图片。

零积分模式不需要 Higgsfield MCP，不上传图片，也不调用远程生成服务。

### 低积分模式

除上述环境外，还需要配置一个兼容的 Higgsfield MCP，并能提供：

- Soul 2.0 图片生成；
- 生成前费用查询能力（若服务端支持）；
- 任务状态或结果查询；
- 可下载的生成图片地址。

模型和工具是否可用取决于朋友自己的 Higgsfield 账号、MCP 配置、地区和额度，本安装包不提供账号或额度。

### 完整渲染模式

需要兼容工作流中人物、分镜、精修、视频、任务查询和媒体处理步骤的 Higgsfield 工具。网站演示、视频拼接或字幕后处理还可能需要 Node.js、Playwright、FFmpeg、FFprobe 和相应字体。实际调用以朋友环境中暴露的工具为准，工具名称变化时应以实时工具定义为准。

## 一键安装

macOS 或 Linux：

```bash
cd higgsfield-ugc-workflows-share-v2.0
bash install.sh "/朋友的项目绝对路径"
```

安装位置固定为：

```text
<朋友的项目>/.agents/skills/higgsfield-ugc-workflows
```

这样不会修改朋友的全局 Codex Skills，也不会影响其他项目。安装完成后，让朋友在 Codex 中打开目标项目；如果该项目已经打开，请重新载入项目或新建一个 Codex 任务，让 Codex 重新发现项目 Skills。

如果目标项目已经安装过同名版本，安装器默认停止。确认需要更新时使用：

```bash
bash install.sh "/朋友的项目绝对路径" --replace
```

旧版本会被移动到项目 `.agents/skill-backups/` 下带时间戳的备份文件夹，不会直接删除。

### 手动安装

不使用安装器时，将本包中的 `skill` 整个复制为：

```text
<项目>/.agents/skills/higgsfield-ugc-workflows
```

复制后必须保持以下结构：

```text
higgsfield-ugc-workflows/
├── SKILL.md
├── agents/
├── references/
├── scripts/
└── workflows/
    ├── ugc-flow/
    ├── ugc-product-flow/
    ├── ugc-saas-flow/
    ├── ugc-try-on-flow/
    ├── ugc-tutorial-flow/
    └── ugc-unboxing-flow/
```

不要只复制 `SKILL.md`。缺少 `workflows/` 时，六条子流程无法加载。

## 安装后验证

在朋友的项目根目录运行：

```bash
python3 .agents/skills/higgsfield-ugc-workflows/scripts/local_workflow_registry.py catalog
python3 .agents/skills/higgsfield-ugc-workflows/scripts/check_mode_contracts.py
```

第一条命令应列出 6 条工作流；第二条命令应返回 `"valid": true` 且 `"errors": []`。

也可以在解压后的安装包目录直接运行：

```bash
bash verify-package.sh
```

## 如何发起任务

安装完成后，可直接在 Codex 中说：

```text
使用 $higgsfield-ugc-workflows。
做一条 15 秒、9:16、英语、女模特的真人产品测评。
使用零积分模式。
模特图：/绝对路径/model.png
产品图：/绝对路径/product.png
参考图顺序：产品图第一，模特图第二。
输出完整口播、文本分镜、视频提示词、参考图顺序和生成后验收清单。
```

更多完整模板见 [示例需求.md](../示例需求.md)。

## 必须遵守的质量规则

- 根据最终画面的主体和动作选择路线，不能因为输入中有 URL 就自动选择网页路线；
- 产品只分析一次，冻结外形、尺寸、标签、结构、真实用法和允许表达的卖点；
- 膏体、凝胶、精华、液体等必须有真实颜色和透明度证据，不能根据包装颜色或产品名称猜测；
- 默认只出现一个目标商品，不复制、不异常放大、不展示参考图没有提供的未知角度；
- 最多两只手，每只手在一个时刻只承担一个主要动作；
- 开盖、挤出、涂抹和穿戴必须按真实物理顺序发生；
- 提示词中的 `@ImageN` 声明必须与实际上传顺序一致；
- 八个镜头只有七个 `Hard cut to.`，四个镜头只有三个，最后一镜不追加转场；
- 用户已有模特图时，低积分请求自动降为零积分模式，避免浪费人物生成；
- 素材不足时停止确认，不猜测，不擅自切换到付费模式；
- 提示词模式不得声称已经生成分镜图或视频成片。

## 文件说明

- `skill/`：可直接安装的完整 Skill；
- `skill/workflows/`：六条自包含子流程及公开预设；
- `install.sh`：项目本地安装器；
- `verify-package.sh`：安装包完整性自检；
- `示例需求.md`：三种模式的请求模板；
- `docs/UGC工作流详细介绍.md`：可发给客户阅读的服务说明；
- `CHANGELOG.md`：版本变更；
- `SHA256SUMS.txt`：包内文件校验值，打包时自动生成。
