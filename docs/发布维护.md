# 维护与打包

在仓库根目录修改文件后，先更新 `VERSION` 和 `CHANGELOG.md`，然后运行：

```bash
python3 scripts/package_release.py
bash verify-package.sh
```

打包脚本更新根目录的 `SHA256SUMS.txt`，并在 `dist/` 生成带 UTF-8 文件名的完整 ZIP 和 ZIP 校验值。将根目录校验清单与源码一起提交；把 `dist/` 的两个文件作为 GitHub Release 附件上传。不要将本地环境文件、素材、账号信息或生成结果提交到仓库。

发布前在一个空的项目目录测试 `install.sh`，确认读取到六条内嵌路线。付费生成流程的验证范围应单独记录，并说明所用服务和模型版本。
